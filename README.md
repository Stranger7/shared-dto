<p>
Компилятор DTO-моделей для PHP и TypeScript
</p>

## Установка

Требования:
- PHP 8.3
- Composer

## Создание новой DTO-модели

- В каталоге `dto/source/` создать yaml-файл с описанием DTO-модели. Структура yaml-файла описана ниже.
- Выполнить из корня проекта `php ./scripts/compile.php`.
- Путь к скомпилированным моделям можно задать в `.env` файле
  По умолчанию DTO модели для PHP находятся в каталоге `dto/php`, для TypeScript в `dto/ts`.

## Структура Yaml-файла
См. примеры в папке `dto/source/Example`

## Тесты
Выполнить из корня проекта `./vendor/bin/phpunit tests`
